# 03 — E-commerce Funnel Intelligence

**Executive question:** Where does the acquisition-to-purchase journey lose efficiency, and which channels deserve deeper investigation?

## Analytical Layers
**Visits → Product Engagement → Cart → Checkout → Purchase → Revenue**

### KPI layer
- Visits
- Purchases
- Purchase Conversion
- Add-to-cart Rate
- Revenue

### Dashboard UX
**Overview → Performance → Drivers → Segments → Deep Dive → Insights → Data Quality**

The UI emphasizes funnel leakage, channel comparison, conversion economics, and a dedicated growth-action layer.

### Decision layer
Email has the strongest conversion rate in the supplied sample at 16.37%, while Social has 2.80% despite significant traffic. The dashboard therefore highlights **Social landing-page/message fit** as an investigation area.

Python • Pandas • SQL • Power BI • Funnel Analytics • Conversion Optimization
