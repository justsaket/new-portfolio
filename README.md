# Data Analytics Portfolio

A portfolio of four end-to-end business intelligence projects built around **Python, Pandas, SQL, KPI analysis, Power BI-style dashboard UX, and business storytelling**.

## Executive Dashboard System

The dashboards have been upgraded from basic static charts into a consistent **executive analytics interface** with:

- Executive KPI cards and variance indicators
- Persistent analytics navigation
- Trend + benchmark views
- Segment and driver analysis
- Deep-dive workspaces
- Matrix / distribution / funnel-style visuals
- Executive signal panels
- Decision/action layer
- Data-quality and drill-through-ready structure
- Consistent dark enterprise analytics design system
