# 04 — Financial Performance Command Center

**Executive question:** Is revenue growth translating into gross and operating profitability?

## Analytical Layers
**Revenue → COGS → Gross Profit → Operating Expenses → Operating Profit → Margin**

### KPI layer
- Revenue
- COGS
- Gross Profit
- Operating Expenses
- Operating Profit
- Gross Margin %
- Operating Margin %

### Dashboard UX
**Overview → Performance → Drivers → Segments → Deep Dive → Insights → Data Quality**

The interface is designed as a management reporting workspace, combining top-line trend, margin movement, cost structure, profitability bridge thinking, and an action layer.

### Decision layer
The supplied sample moves from ₹8.50L revenue in January to ₹13.40L in August, while operating profit moves from ₹0.65L to ₹2.22L. The dashboard keeps the focus on **growth quality and margin sustainability**, not revenue alone.

## Stack
Python • Pandas • SQL • Power BI • DAX • Financial Analysis • Management Reporting
