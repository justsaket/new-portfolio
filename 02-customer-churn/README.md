# 02 — Customer Retention Intelligence

**Executive question:** Which customer segments show churn signals, and what customer behaviors should be investigated before designing retention actions?

## Analytical Layers
**Customer Base → Churn → Plan → Tenure → Engagement → Support → Risk Investigation**

### KPI layer
- Customers
- Churned Customers
- Churn Rate
- Average Tenure
- Average 30-day Logins

### Dashboard UX
**Overview → Performance → Drivers → Segments → Deep Dive → Insights → Data Quality**

The dashboard separates observed churn patterns from interpretation and makes the sample limitations visible.

### Decision layer
The supplied sample shows higher churn rates in Basic and Standard plans than Premium. Churned customers also show different login/support patterns. These are **descriptive sample patterns, not causal proof**.
