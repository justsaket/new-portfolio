# Portfolio UI/UX Design System

## Product direction
The portfolio is designed as an **Executive Analytics OS**, not a collection of isolated charts.

### Layout
- 1600×1000 executive canvas for dashboard previews
- 230px navigation rail
- Persistent context/header bar
- 4 KPI cards above the fold
- Primary analytical workspace
- Secondary diagnostic workspace
- Bottom decision/action layer

### Visual hierarchy
1. Business outcome
2. KPI signal
3. Driver
4. Segment/deep dive
5. Recommended investigation
6. Measurement / next action

### Interaction-ready information architecture
Every dashboard is structured so it can be translated into Power BI:
Overview → Performance → Drivers → Segments → Deep Dive → Insights → Data Quality.

### Design principles
- High information density without visual clutter
- Consistent spacing and typography
- Strong contrast and restrained accent usage
- Domain-specific accent colors
- Evidence separated from interpretation
- Simulation/sample data explicitly labeled
- Decision support without pretending correlation is causation

### Portfolio quality bar
A project should show:
**Business question → data model → KPI logic → analysis → visualization → insight → action → measurement.**
