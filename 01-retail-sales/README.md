# 01 — Retail Sales Intelligence

**Executive question:** Where is revenue being generated, where is profit concentrated, and where should management investigate margin pressure?

## Analytical Layers
**Revenue & Profit → Margin → Region → Category → Product → Exception → Action**

### KPI layer
- Revenue
- Cost
- Profit
- Margin %
- Units

### Dashboard UX
**Overview → Performance → Drivers → Segments → Deep Dive → Insights → Data Quality**

The interface uses a persistent executive navigation rail, KPI command cards, trend/benchmark workspace, regional/product driver analysis, and an action center.

### Decision layer
The sample shows Electronics as the largest revenue contributor and South as the largest regional profit contributor. West is the lowest regional profit contributor in the supplied sample; the dashboard therefore frames **mix/pricing investigation** rather than asserting a cause.

## Stack
Python • Pandas • SQL • Power BI • DAX • Data Visualization
