# Power BI Portfolio Guide

This repository now contains four Power BI-ready dashboard specifications, polished SVG dashboard mockups, DAX measures and detailed business insights.

## Build in Power BI Desktop
1. Import each CSV.
2. Rename the tables to match the DAX references.
3. Create the listed measures.
4. Recreate the dashboard layouts from dashboard.svg.
5. Add slicers, drill-through and tooltips.
6. Export the finished dashboard as PDF/images for your portfolio.

## Portfolio structure
Problem → Data → Cleaning → Dashboard → Insights → Business Actions → Tools.

Note: a native .pbix file must be created/saved using Power BI Desktop; the repository provides the complete build specification and visual reference.
